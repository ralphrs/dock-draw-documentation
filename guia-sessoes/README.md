# Guia das sessões A e B

| Arquivo | Para quê |
| --- | --- |
| `PROTOCOLO.md` | Regras de comunicação: pastas, nomes, ciclo de vida, posse, aprovação humana, escuta |
| `PROMPT-SESSAO-A.md` | Primeira mensagem da sessão arquiteto (nova) |
| `PROMPT-SESSAO-B.md` | Mensagem para a sessão executora (já rodando) |
| `CONFIGURACAO.md` | Ajuste no `.claude/settings.json` e ordem de início |
| `templates/` | Modelos de tarefa, dúvida e resposta |
| `bin/` | `wait-for.sh` (escuta), `move.sh` (publica, move e registra no LOG), `next-id.sh`, `seen.sh` |
